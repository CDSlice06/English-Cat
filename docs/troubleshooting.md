# 常见问题排查

按「现象 → 原因 → 处理」组织。云函数相关问题先在**云开发控制台 → 云函数 → 日志**里按函数名查看，前端问题用真机调试看 `console`。

## 一、导入与文档解析

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 上传后报 `-504003 timed out after 3 seconds` | 云函数超时仍是默认 3 秒（`config.json` 的声明未同步到控制台） | 控制台把 `parseDocument` 超时改成 60s；导入页已内置「超时自动重试一次」 |
| 提示「没有足够英文正文」 | 扫描版 PDF（整页是图片、没有文字层），或 PDF 二进制流里混入了图片/字体字节 | 零依赖解析无法处理扫描件，提示用户上传文字版或粘贴原文；图片对象流已在解析器里跳过 |
| 正文出现 `¡ª` 之类乱码 | 中文排版 PDF 用 GBK 双字节保存破折号/引号 | 已按 GBK 标点表还原；若复现，取原 PDF 复现并比对字节 |
| 整卷真题拆出的篇数不对 | 自动跳页规则：有效页 ≥10 裁到 9 页、6–9 页从第 4 页开始、5 页从第 2 页开始、≤4 页从第 1 页开始 | 对照文件实际有效页数确认；只保留仔细阅读正文并拆成多篇 |
| 导入后没反应、也没跳页 | 导入只入库（`queued:true`），不解析、不消耗模型额度 | 到题库页主动打开该篇才会解析并跳词汇页，这是设计如此 |

## 二、AI 精讲与模型

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 报「大模型未配置」 | 云函数缺 `DEEPSEEK_API_KEY` | 控制台 → 云函数 → 配置环境变量（`llm`、`parseDocument` 都要） |
| 报「词典加载失败」 | `analyzeArticle` 字典文件没随函数上传 | 右键 `cloud/analyzeArticle` **整个目录**上传并部署 |
| 每篇文章练习题都一样 | 精讲没真正跑起来，退回规则库兜底示例题 | 确认 `aiStatus` 会从 `pending` 触发；确认线上 `analyzeArticle` 是最新版 |
| 一直卡在「精讲中」 | 云函数被 60s 上限杀掉，`aiStatus` 卡在 `running` | 超过 5 分钟允许重新触发；两阶段（选点 + 讲解）最长约 2 分钟，轮询窗口要覆盖 |
| 精讲结果没生效 | 写入前有 `updatedAt` 版本校验，模型运行期间文章被重新解析过 | 重新进入工作台触发一次即可 |
| 做了没做的题显示「已通过」 | 旧判题记录复用了同一个 drill id | 精讲替换题目内容后会按 id 比对 prompt/reference 清理旧记录；若复现，检查该篇是否走了老版本逻辑 |

## 三、词汇与词频

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 整页都显示「词频未收录」 | 文章是词频功能上线前解析的旧数据，词条里没有 `freq` | 词汇页进入时会用词库批量补查；若仍全空，说明线上 `analyzeArticle` 是旧版，重新上传该函数 |
| 单词释义错乱（如 `rates` 被当成 `rat`） | 词形还原顺序问题 | 已改为优先匹配 `/s$/` 再 `/es$/`；复现请带原词反馈 |
| 词数比文章里看到的单词少 | 抽取按篇幅取（约每 8 词留 1 个，20–60 条），已记住的词会跳过 | 属正常口径，不是丢词 |
| 释义里混进拼写批注 | 模型输出污染 | 已加三层校验（禁批注、清洗含「原文/拼写/应为」的释义、整词回查）；复现请提供词条 |

## 四、进度与通关口径

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 词汇站怎么点都不通关 | 历史上出现过「分母 > 可点到的卡片数」死局 | 现口径为**本篇全部单词掌握**，默认筛选固定「全部词汇」；若复现，检查前端 `vocabStats` 与云函数 `vocabProgressOf` 是否同版本 |
| 掌握篇数比之前少 | 通关口径收紧（曾按核心词判，现按全量判） | 预期变化，不是 bug |
| 想换文章被拒绝 | 当前文章进度 > 35% 且未完成 | 属预期；学完 100% 可换，或先重置进度 |
| 某一站为空却卡住 | 空内容站应直接判通过 | 若卡住说明该站 `checks` 判断反了，需同时改前端 `getProgress` 与云函数 `study` |
| 首页/工作台数字与词汇页不一致 | 两侧口径不同源 | 检查是否都走 `services/study.js` 的 `vocabStats` / `getProgress`，云函数侧 `study` 是否已重新部署 |

## 五、收藏本与复习

- 生词本、词组本、语法与句式本三类数据**完全隔离**；删除文章会连带清理 `article_units` 与 `attempts`，但**不动**收藏本。
- 「今日复习」只复习「不记得」的词，只有点「记得」才会改成已掌握；「不记得」只写本地 `reviewLog`。若状态没变，检查是否点的是「不记得」。
- 词组本收录时会过滤伪搭配（系动词+形容词、介词+动名词、动词+副词）；若发现误收，反馈搭配原文。

## 六、发音

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 真机没声音、开发者工具正常 | 合法域名未配 | 开发设置 → downloadFile 合法域名加 `https://dict.youdao.com`，并取消「不校验合法域名」后真机复测 |
| 两个喇叭同时停在播放态 | 旧音频回调被覆盖 | 已改为播放新词前先收尾上一条；若复现请记录机型 |
| 点发音提示网络异常 | 有道接口不可达或超时 | 检查手机网络；接口免费无需密钥 |

## 七、数据与权限

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 报 `-502001 multiple write errors` | 用空对象作为 `update` 的 `data` | 清空字段用 `_.remove()`；历史重复 `article_units` 文档需清理 |
| 用户看不到自己的文章 | 数据按 `openid` 隔离 | 正常；跨账号只能共享「同一篇正文的精讲缓存」 |
| 担心数据泄露 | 平台默认权限可能放开读写 | 10 个集合权限必须全部为 `false`（只允许云函数访问），与 `cloud/database.json` 声明一致 |
| 解析结果丢失/被覆盖 | 并发精讲互相覆盖 | 已有 `claimEnhance` 抢占 + `updatedAt` 条件写入；若复现请提供文章 id 与时间点 |

## 八、报告卡片与分享

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 「存成手账卡片」没保存成功 | 未授权相册 | 首次会弹授权；拒绝后按提示去「设置」开启，或从右上角菜单重新授权 |
| 存出来的图被裁掉一半 | `canvasToTempFilePath` 传了画布像素尺寸 | 已改为只传 `destWidth/destHeight`，由接口按整块画布导出 |
| 分享封面不对 | 分享图取自 `miniprogram/assets/share`（5:4 与 1:1 两张） | 换图直接替换这两张，文件名保持不变 |

## 九、排查入口速查

- **本地快照**（首屏加速用，24h 过期）：`studySnapshot`、`wordbookSnapshot`。
- **断点续接**：`resume_<articleId>`，记录 `{ station, id, at }`；工作台据此显示「继续上次」。
- **复习记录**：`reviewLog`（本地，记录每词上次复习时间）。
- **判题日志**：`evaluateTranslation` 的语法校验分支带统一前缀，可按关键词过滤；`EVAL_LOG=off` 可关闭。
- **重置手段**：个人中心「重置进度」清空当前文章学习记录；排查缓存类问题时可在开发者工具 Storage 面板删本地 key。
- **改了云函数就必须重新上传对应函数**，只提示上传前端代码是无效的。
