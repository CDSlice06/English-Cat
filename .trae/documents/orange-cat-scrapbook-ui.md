# 英语喵 · 橘猫手帐风 UI 改造计划

## Context

当前界面功能完整，但卡片、渐变和胶囊标签重复较多，页面之间视觉差异不足，橘猫主要只作为插图出现。用户提供的参考图值得借鉴的是「纸张手帐」的层次：奶油纸底、手绘描边、胶带与书签、错落硬影、雾蓝和焦糖色点缀，而不是照搬其中的形象或排版。本次目标是把这种语言转成英语喵自己的橘猫学习手帐，同时保持所有功能、路由、数据和学习顺序不变。

## 设计方向

- **主色不变**：奶黄纸张 + 蜜橘主按钮；增加雾蓝、焦糖、深咖描边作为层次色。
- **猫猫成为设计语言**：猫爪进度印记、胡须标题线、猫耳轮廓、猫爪水印、橘猫贴纸和错位便签，而不只是摆放插图。
- **手帐层次**：纸纹、2rpx 深咖细描边、不对称圆角、错位硬影、半透明纸胶带、虚线缝线；装饰不进入点击区域。
- **克制与可读**：仅首页/学习页做完整示范，学习流程页统一继承；不新增外部图片、字体、组件库或第三方依赖，继续复用 8 张橘猫透明 PNG。

## 实施步骤

### 1. 建立共享纸张与猫爪语言

修改 `miniprogram/app.wxss`：

- 增加雾蓝、焦糖、手绘描边和硬影令牌，页面背景叠加低对比纸纹与稀疏爪印。
- 增加可复用的 `.paper-card`、`.paper-tape`、`.paw-print` 等轻量样式；爪印只用 radial-gradient，胶带只用半透明渐变、边框和旋转。
- 底部操作栏改成带缝线的奶油纸托，不改动现有 `env(safe-area-inset-bottom)` 和 `.has-bar` 预留空间。

### 2. 升级共享组件，让所有页面自然继承

- `components/section-title/index.wxss`：标题前短线改为猫胡须组合，标题区加入浅色猫爪印章；保留现有 WXML 和属性。
- `components/primary-button/index.wxss`：主按钮改成焦糖橘手帐标签，带深咖描边、错位硬影和浅爪印水印；次按钮保持纸白，禁用/按压状态同步。
- `components/progress-bar/index.wxss`：轨道改为纸色缝线槽，填充保留蜜橘渐变，进度数字和刻度增加手帐感。
- `components/cat-image/index.wxss`：保留原 PNG 和柔和浮动，阴影从 `filter` 改为径向渐变，降低真机兼容风险。

组件样式隔离，装饰写在组件自身 WXSS，不依赖全局类穿透。

### 3. 首页做成完整的「橘猫精读手帐」

修改 `pages/index/index.wxml` 与 `index.wxss`，JS 数据不变：

- 顶部品牌区改成「MIAO 手帐社」式小标签，保留「英语喵」产品名与等级标识。
- Hero 改为奶油纸+蜜橘便签的叠层结构，增加纸胶带、猫耳轮廓、角落爪印和橘猫便签；标题、文章数据、学习步骤保持原位置与含义。
- 当前文章进度卡加入书签角标和猫爪式步骤轨迹，继续阅读按钮沿用共享组件。
- 四个功能卡保留两列与现有 tone，改成不同纸色的手帐卡：编号变便签签条、奇偶卡轻微错落、焦糖/雾蓝交替硬影、底部浅爪印和现有橘猫插图。
- 小贴士改成横线便签，页脚保留安静收尾。

### 4. 学习页改成「四站猫爪学习路线」

修改 `pages/workbench/index.wxml` 与 `index.wxss`，JS 不变：

- 概览卡增加胶带、纸张叠层和精读徽章。
- 四个单元卡使用连续虚线/爪印路线串联，编号变成彩色爪印站牌；不同单元保留各自色彩和橘猫，完成状态仍清晰。
- 学习报告入口改成可撕便签/贴纸卡，强调最终成果，不改变点击逻辑。

### 5. 学习流程页轻量统一，不重写交互

仅调整 `pages/vocabulary`、`phrases`、`analysis`、`practice`、`summary` 的代表性 WXSS，必要时添加无交互装饰节点：

- 核心卡、词组卡、语法卡、练习卡和报告卡统一为奶油纸、手绘细描边、局部硬影/缝线；不同页面分别使用词卡、索引签、拆解笔记、练习纸、完成证书的视觉隐喻。
- 保留现有展开、输入、评分、横滑题号、底部按钮和安全区；不改 JS、services、cloud、app.json 或路由。
- 所有新增装饰设 `pointer-events: none`，新增动效纳入 `prefers-reduced-motion`，原有减弱动效规则继续有效。

## 验证

1. 使用开发者工具自动化端口 `ws://127.0.0.1:9421`，首页/学习页用 `switchTab`，其余页用 `reLaunch`。
2. 用同一篇示例文章依次检查首页、学习页、词组、语法、练习、报告并截图；确认装饰不盖文字、不拦截点击，长标题、展开卡、输入框和反馈区无错位。
3. 重点检查窄屏两列卡、练习页横向题号、固定底栏与最后内容间距；复查减弱动效下无漂浮、入场或按压位移。
4. 最后再走一次「词汇 → 词组 → 语法 → 输出」导航，确认本次纯视觉改造没有改变功能和学习顺序。
